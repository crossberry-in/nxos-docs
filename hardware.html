Architectural facts used (ARMv8-A / GICv2 specifications)

  • Exception vector table: 16 × 128-byte slots, VBAR_EL1 2 KiB aligned.
  • ESR EC encodings: SVC AArch64 0x15, data/instruction aborts, SError.
  • MAIR AttrIdx 0 = normal WB-RWA (0xFF), AttrIdx 1 = Device-nGnRE (0x04); descriptors: AP/SH/AF/nG/PXN/XN bit layout per ARMv8-A.
  • TCR: 4 KiB granule, T0SZ/T1SZ = 16 (48-bit VA), inner-shareable.
  • GICv2 register offsets (CTLR/IGROUPR/ISENABLER/ICENABLER/ICPENDR/ ICFGR, GICC CTLR/PMR/IAR/EOIR) per the GICv2 architecture spec.
  • INTID 1022 = "no visible interrupt", 1023 = spurious.
  • CPACR_EL1.FPEN must allow FP/SIMD at EL1 or the first NEON instruction (compiler-generated wide copies) traps as Undefined.

The platform::qualcomm::sm4450 module intentionally contains no hardware addresses. devices/xiaomi/sky/device.toml records the publicly known descriptive profile (SoC, CPU topology, display, storage) and marks every bring-up field UNVERIFIED.

The GIC driver's Group 0 choice is derived from the QEMU boot contract (Secure EL1). The phone's boot-time security state is unknown; the driver must be re-evaluated before any phone bring-up.
